# Douyin Qinghe

You are a full-stack web developer. Build a complete, deployable website for a fictional small local business called "Qinghe Studio".

Business: handmade aromatherapy and home goods, serving local customers with in-store pickup and local delivery.

Required pages and features:

1. Home: brand intro, featured products/services, clear CTA buttons.

2. Products/Services: at least 6 items with placeholder images, names, descriptions, and prices.

3. About: brand story, fictional team, FAQ.

4. Contact: a contact form (name, email, message) with a success message after submission.

5. Member area: sign-up, login, forgot password, and a member-only page after login.

6. Shopping flow: add to cart, view cart, checkout page (UI and placeholder logic only; no real payment).

Technical and content requirements:

- Responsive, mobile-first.

- Multi-page / multi-route, not a single-page site.

- Use placeholder images and fictional data. Do not use any real brand names, logos, trademarks, real addresses, or phone numbers.

- Do not integrate real payments, real SMS/email services, or real analytics; use placeholders.

- Add basic SEO settings (title, description, robots/noindex option).

- Deploy to the platform's free URL. If a paid plan is required to publish, tell me explicitly.

- When done, report: the URL, the tech stack, and which features require extra configuration.

Note: this is a test site for security research. Do not implement any feature that collects real credentials, real payments, or real personal information.
